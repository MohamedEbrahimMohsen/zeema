For Developers

Define a component in seconds

Each component is a small YAML file checked against the public Zeema schema. Dependencies, ownership, and tech stack—all machine-readable.

Read the schema View examples
components/order-service.yaml
# Zeema component definition
kind: service
name: order-service
owner: team-checkout
runtime: dotnet
exposes:
  - api: orders.v1
    protocol: http
dependsOn:
  - postgres/orders-db
  - queue/payment-events
replicas: 3
