Cloudflare component icons in this folder
=========================================

The files in icons/components/cloudflare/ that carry no "generated by icons.mjs" marker are
Cloudflare's own product icons, scaled into a 24 unit box, coordinates rounded, and painted in
Cloudflare orange (#F38020). .claude/tools/vendor-icons/cloudflare.json names the source of each.
They come from two places, under two licences. Cloudflare's trademarks remain Cloudflare's; the
icons are used only to identify the product a component models.

1. Cloudflare developer documentation product icons
   Source:  https://github.com/cloudflare/cloudflare-docs, src/icons/,
            commit 1805e7cc6c565a8d94eb633c41596758d2025cc0 (branch production)
   Author:  Cloudflare, Inc.
   Licence: Creative Commons Attribution 4.0 International (CC BY 4.0),
            https://creativecommons.org/licenses/by/4.0/
   Changes: fitted to the 24 unit box, coordinate precision reduced, colour set to #F38020.
   Used by every Cloudflare icon here except the one listed under 2.

2. @cloudflare/component-icon 13.15.3 (npm), source in https://github.com/cloudflare/cf-ui
   Used by: cloudflare-workers-for-platforms (WorkersForPlatforms)
   Changes: the React component's SVG markup extracted, fitted to the 24 unit box, coordinate
            precision reduced, colour set to #F38020.
