# Mingrammer non-node sections

The `generic`, `programming`, `c4` and `gis` sections of <https://diagrams.mingrammer.com/docs/nodes/>
hold shapes, languages, frameworks, notation and desktop tooling rather than architecture
components. They are recorded here so the coverage of the mingrammer node set is auditable;
every row is a deliberate `skip`. A handful of `generic` entries that are real products
(`generic/os` operating systems, `generic/virtualization` hypervisors) are cross-referenced to
their `default` component when one exists.

Status: `skip: <reason>` throughout.
