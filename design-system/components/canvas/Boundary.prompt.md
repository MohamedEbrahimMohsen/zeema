One-line: the dashed frame that groups nodes into a region, account, VPC or trust boundary.

```jsx
<Canvas><Boundary label="us-east-1 (region)" />…</Canvas>
```

Always dashed, always `--frame` (a neutral that sits between line and muted), never filled — a filled boundary would compete with the taxonomy fills it contains. The label is mono and states the boundary type in parentheses.
