One-line: a directed connection between two nodes.

```jsx
<CanvasEdge x={132} y={77} length={60} />
<CanvasEdge x={132} y={77} length={60} dashed={false} />
```

Dash style is semantic: **dashed is asynchronous** (a queue, a topic, a stream), **solid is synchronous** (a call). 1.2px in `--muted` — edges are the quietest thing on the canvas so the nodes carry the colour.
