One-line: names a region of a panel or sheet — mono, uppercase, tracked out.

```jsx
<SectionLabel>Findings</SectionLabel>
<SectionLabel>Component rows · icon first</SectionLabel>
```

Written in sentence case in source (`Findings`) and uppercased by `--lab-tt`, so a density swap can turn the treatment off in one token. Use a middle dot `·` to append a qualifier.
