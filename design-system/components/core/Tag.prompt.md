One-line: a pill for metadata that qualifies a thing — provider, visibility, reference state.

```jsx
<Tag mono>aws</Tag>
<Tag>private</Tag>
<Tag tone="danger">broken twin</Tag>
```

Use `mono` for anything the system owns (`aws`, `azure`, `gcp`); plain sans for human words (`private`, `reference`). Never fill a tag — Arkore tags are outline-only.
